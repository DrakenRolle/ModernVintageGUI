# The showcase as the J hotkey opens it, and the two things that draw outside of it.
#
# Run with:   ZIngameShots\ingame-screenshot.ps1          (this file is the default)
#
# Steps:      wait N            N rendered frames; "wait 2s" / "wait 500ms" waits by the clock
#             open              the showcase dialog
#             close             hides it again
#             shot FILE         full window capture into the output directory (.png)
#             dropdown NAME     opens the dropdown with that Name; "dropdown NAME close" closes it
#             menu OWNER        shows the context menu attached to that control; "menu OWNER close" hides it
#             hover NAME        moves the cursor onto a control
#             click NAME        presses and releases the left button on a control
#             quit              leaves the world - which saves it - and closes the game
#
# The pipeline appends "quit" when a script does not end with one (unless -KeepOpen).

wait 2s                     # let the world settle after loading
open
wait 10
shot showcase.png

dropdown textDropdown       # the list is a popup outside the dialog
wait 5
shot showcase-dropdown.png
dropdown textDropdown close

menu menuButton             # so is the context menu
wait 5
shot showcase-menu.png
menu menuButton close

hover saveButton
wait 5
shot showcase-hover.png
